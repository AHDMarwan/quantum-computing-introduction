# Learning from Quantum Data

## 1. A fundamentally different QML regime

Many QML discussions start from classical vectors and ask how to encode them into qubits. Learning from quantum data starts elsewhere: the input is already a quantum object.

Examples include

```math
\rho,
\qquad
\mathcal E,
\qquad
H,
\qquad
\text{multi-time quantum process}.
```

This setting is often more naturally quantum because converting the input into a complete classical description can itself be expensive.

## 2. Quantum-state learning

Tasks include

- state discrimination,
- tomography,
- fidelity estimation,
- property prediction,
- phase-of-matter recognition,
- and prediction of observables.

The resource may be the number of copies of $\rho$, the number of measurement settings, or the quantum memory available across copies.

## 3. Collective versus separate measurements

Suppose the learner receives

```math
\rho^{\otimes N}.
```

It may measure copies separately, adaptively, or collectively. A joint measurement on multiple copies can access information unavailable to a fixed sequence of independent measurements at the same copy count for some tasks.

Thus the measurement architecture itself can be a learning resource.

## 4. Quantum-channel learning

An unknown process

```math
\mathcal E
```

can be queried with selected input states and measurements. Tasks include channel tomography, discrimination, property testing, and prediction of future behavior.

Entangled probe states and adaptive strategies can change information efficiency.

## 5. Hamiltonian learning

If data are generated by

```math
U(t)=e^{-iHt},
```

the task may be to infer parameters of $H$, interaction graphs, phases, or effective dynamics from experiments. This connects QML with system identification, metrology, and many-body physics.

## 6. Multi-time processes

When the environment has memory, a single state or channel may be insufficient. Process tensors or quantum combs describe multi-time input-output behavior under interventions. Learning such objects is closer to learning a dynamical causal process than fitting an i.i.d. dataset.

## 7. Experimental quantum learning advantage

Results on learning from quantum experiments have shown rigorous separations where a quantum processor retaining coherent access to experimental quantum states can require dramatically fewer experiments than strategies that measure each state and keep only classical data, for specifically constructed prediction tasks.

The conceptual lesson is important:

```math
\boxed{
\text{the advantage may come from preserving quantum data, not from encoding classical data}
}
```
