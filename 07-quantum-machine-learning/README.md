# Quantum Machine Learning

Quantum machine learning (QML) studies learning problems in which quantum information processing, quantum models, or quantum data play a substantive role. It is a field, not a single algorithm and not a synonym for parameterized quantum circuits.

## Three axes to keep separate

A QML problem should specify at least:

1. **data type/access:** classical samples, coherent oracle access, or quantum states/processes;
2. **model/computation:** PQC, kernel, channel, measurement policy, reservoir, tensor network, etc.;
3. **learning task:** classification, regression, generation, control, property prediction, state/process learning, or another operational goal.

A claimed advantage is meaningful only relative to explicit resource and access assumptions.
