# Educational Figures

These figures are generated with Plotly for the educational chapters in this repository.

The goal is explanatory rather than decorative: each figure is used where geometry, state-space structure, correlations, probability distributions, or an algorithmic transformation is easier to understand visually.

## First figure set

- `bloch-sphere-state.svg` — a pure qubit as a Bloch vector.
- `bloch-ball-pure-mixed.svg` — pure, mixed, and maximally mixed one-qubit states.
- `measurement-bases-bloch.svg` — measurement axes on the Bloch sphere.
- `tensor-product-basis.svg` — the four computational basis states of two qubits.

The SVG format is used because it renders directly on GitHub and remains sharp when zoomed.
