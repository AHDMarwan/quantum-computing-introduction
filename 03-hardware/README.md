## Comparison axes

When comparing hardware, ask about

- physical encoding,
- native gates and interactions,
- coherence,
- gate and measurement fidelity,
- connectivity,
- operation speed,
- fabrication and control,
- leakage and dominant noise mechanisms,
- scalability,
- and error-correction compatibility.

No single scalar metric determines the “best” platform.
